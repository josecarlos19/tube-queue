YouTube API key

TubeQueue uses this key to find channels and fetch their latest uploads. Only public data is read.

The key is stored locally in SQLite and used by the server only.

Create your own API key

  1. Create or select a project in Google Cloud Console.
  2. Enable YouTube Data API v3 in APIs & Services → Library.
  3. Create credentials → API key, then restrict it to YouTube Data API v3.
  4. Paste the key above and save. Keep it private.
